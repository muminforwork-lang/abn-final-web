ABNORMAL LOCAL CHARACTER ART
============================

Everything in this folder is served locally. The website does not fetch anime art from online APIs and does not need a network connection to display character artwork.

Add images to `characters/` using these names:
  anemo.png         first variant
  anemo2.png        second variant
  anemo3.png        third variant
  electro2.png      second Electro-colour variant
  cryo 2.webp       numbered names with a space also work

The same naming convention works for all theme folders/IDs. Supported formats are PNG, WebP, AVIF, JPG, and JPEG. If two formats exist for the same numbered variant, WebP/AVIF are preferred before PNG/JPEG. The site rotates across local variants automatically.

Optional mobile companions use names such as `anemo.mobile.webp` and `anemo2.mobile.webp`. Transparent PNG/WebP cut-outs are recommended. An opaque image background is not removed automatically.
